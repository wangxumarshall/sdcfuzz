### 关键过程事实
1. **依赖**：bison/flex/g++ 本机已装齐，未动 sudo。
2. **获取**：GitHub 直连不可用（全局 git 配置重写到 gitclone.com 且 502）；ghproxy 完整克隆遇 HTTP/2 流中断；`--depth 1` + `http.version=HTTP/1.1` 成功。
3. **aarch64 编译**：mcpat.mk 去除 `-m32` 和 `-msse2 -mfpmath=sse`（x86 专用），`make opt -j8`（严守 MCE 限制）一次通过，仅上游已知的 powergating.cc 缺 return 警告。
4. **回归**：A9 模板输出与适配前完全一致（5.39485 mm² / 1.74187 W），证明编译补丁无副作用。
5. **踩坑 1**：McPAT 解析器无条件要求组件节点序列完整（L1Directory/L2Directory/NoC 占位组件即使数量为 0 也必须存在）。
6. **踩坑 2**：64-entry 2-way BTB 触发 CACTI `no valid data array organizations`——逐参数二分定位到 sets-per-way≥16 约束，用 block_width=2B 解决（已在 XML 注释说明）。
7. **参数来源**：kunpeng.md + Chips and Cheese 2025-07-22 实测（GPR rename 112 / FPR 96 / scheduler ~33）+ 本机 sysfs（L2 实测 8-way，纠正了 kunpeng.md 未给出相联度）。曾尝试从 gem5 上游找 TSV110 模型（不存在此类），已如实记录。
