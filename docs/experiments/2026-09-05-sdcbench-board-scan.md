- 4 板全部同型鲲鹏920 (MIDR 0x48/d01), corpus 期望在本机录制 — 同构对照,
  终态天然一致, 检出 0 符合预期 (与历史 24h 4 板扫描 0 真 SDC 一致).
- gem5 100% SDC 检出率 ≠ 真机检出率: 前者测"损坏传播性"(ACE), 后者测
  "CPU 自发错误". 断层如实记录.
- 这批序列的真机价值 = 高灵敏度阳性探针 (无掩蔽路径): 一旦有核真出错,
  这些序列最不可能漏报; 0 issues 是未触发的干净基线.
