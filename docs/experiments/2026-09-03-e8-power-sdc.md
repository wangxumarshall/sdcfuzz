# E8: 功耗应力与 SDC 检出率因果关系 (scheme §5.3 H1/H2 框架内首检)

日期: 2026-09-03 | 结果: 方向性信号 + 统计 INSUFFICIENT

## 设计
- A 组 baseline (种子) / B 组 Type-I 持续高功耗 / C 组 Type-II 高低交替
- 各 3 候选 × gem5 bit×15 注入 (McPAT 功耗 + Unicorn toggle 代理同测)

## 结果 (真实 gem5, 135 次注入)
| 组 | 检出率 | mcpat | toggle_proxy |
|---|---|---|---|
| A baseline | 0/15 = **0.0%** | 2.5238W | 0.0164 |
| B Type-I | 3/45 = **6.7%** | 2.5238W | 0.0082 |
| C Type-II | 6/45 = **13.3%** | 2.5238W | 0.0047 |

**方向信号**: A < B < C 单调上升; Type-II (振荡) > Type-I (持续) —
与 scheme §5.3 H2 (跳变更易触发) 的**方向一致**。
**统计**: Fisher B-vs-C OR=0.464 p=0.48; A-vs-C p=0.32 → INSUFFICIENT
(45 样本/组, 检出 13% vs 0% 需 ~100+/组)。

## 三个诚实观察
1. **McPAT duty 映射无组间区分度**: 三组同 2.5238W — B/C 都是 add/eor
   主导 → 相同 duty。当前指令构成→duty 的映射粒度对"应力模式"不敏感
   (持续 vs 交替在构成统计上相同)。改进方向: duty 的**时序波形**建模
   (McPAT 不支持, 需 gem5 stats 周期级功耗或真机 PMU)。
2. **toggle_proxy 方向相反**: 应力块稀释 per-insn 翻转均值 — 代理指标
   的口径陷阱, 诚实记录。
3. **物理边界**: gem5 O3 无电压/时序模型, 仿真中 Type-I/II 只是指令
   构成差异。真实 di/dt 功耗-SDC 因果需真机 (Layer 3/4, 分布式扫描的
   stress-ng di/dt 放大路径) 验证。本实验检验的是框架能诚实回答的部分:
   指令构成维度的应力与检出率是否同向 — 答案: 是 (单调), 但不显著。
